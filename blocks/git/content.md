## Saving your work (git)

- This is a git project: git keeps a running history of the work so nothing is lost.
- Offer to save progress with a commit in everyday language ("shall I save this?"). The first time, explain in a sentence that a commit is a snapshot you can always go back to.
- Keep each commit to one working change, so any single step can be undone on its own.
- Write the commit message in plain English, saying what changed and why, so it reads like a note to the person you are helping.
- Use the name and email already configured in git when you make commits.
