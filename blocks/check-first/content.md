## Check, don't recall

- Search this codebase before answering a question about how it works. What is
  here beats what you remember.
- For anything external - a library's API, a CLI flag, an error message, a
  standard - check the docs or the installed source rather than recalling it.
- Say which you did. "I read `src/auth.ts`" and "I'm going from memory" are
  different levels of confidence, and the reader needs to know which one this is.
