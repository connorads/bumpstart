## When an install is refused

- The package managers here wait a few days before using a brand-new release, and
  refuse a couple of install routes that can run code. Most hijacked releases are
  caught in those first few days, so the wait is the point.
- If an install is refused, read the error and say which control stopped it, in
  plain words. A refusal is information, not an obstacle.
- Never switch a control off globally to get past it. Ask first, explain what the
  refusal means, then allow the single package that needs it - nothing wider.
