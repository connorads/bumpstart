# React

- Prefer function components and hooks; avoid class components.
- Keep components small and focused; lift state only as far as it needs to go.
- Derive state where you can rather than duplicating it in `useState`.
- Name effects by what they synchronise; keep dependency arrays honest.
- Reach for a framework (e.g. Vite) for new apps rather than hand-rolling tooling.
